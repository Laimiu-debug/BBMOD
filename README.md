# BBMOD

《战场兄弟》1.5.2.3 的 Windows 桌面管理器与 MOD 资源合集。

## 下载测试版

[下载 BBMOD.exe](https://github.com/Laimiu-debug/BBMOD/releases/download/v0.3.0-rc.4/BBMOD.exe) · [版本说明与全部附件](https://github.com/Laimiu-debug/BBMOD/releases/tag/v0.3.0-rc.4)

当前发布为 **0.3.0-rc.4 测试版**，新增版本管理、自动检查更新和校验后重启更新；独立汉化沿用 rc.2。单文件 EXE 内置独立汉化词库、字体和启动组件，无需安装 Python。请自行安装受支持的 Steam 原版 1.5.2.3 及相应 DLC；首次运行后选择游戏目录，在「汉化工坊 → 汉化管理与启动」生成并应用独立汉化。第三方汉化和显星 MOD 需要另外安装。

**已知问题：隔离测试副本的中文启动尝试失败，原因尚未定位；新版的游戏内显示、完整流程及第三方 MOD 组合尚未验收。请按测试版使用，不作为稳定版推荐。** 已按用户要求停止游戏测试，发布检查仅离线进行。个人存档校验未变化。

## 管理器

- **营地总览**：游戏定位、DLC、MOD 依赖与上次启动日志诊断。
- **MOD 军械库**：仓库浏览、安装、启用、禁用与方案保存。
- **汉化工坊**：本体与官方 DLC 目录中的 13,433 条非地名文本、2,196 条地名均已独立精修；合并补充界面词条后可编辑 15,815 条。自有显示适配器与 ZIP 构建，不依赖狐狸汉化文件。当前版本通过离线检查，尚未进行游戏内验收。
- **种子远征**：属性、人物特质与地图筛选；58 种开局特质支持必选、排除和全部／任意匹配，可单独筛特质或与能力值组合。实时结果、一键复制、弹幕文案、TXT 导出与可恢复的文件会话。
- **版本与更新**：点击右上角版本按钮，查看软件和内置汉化版本、发布历史与更新说明；支持稳定版／测试版通道、后台自动检查、手动下载和重启更新。首次从 rc.3 或更早版本升级需手动下载本版，此后可在软件内更新。

界面采用手绘营地插画、金属盾徽、木质底板、卷轴面板与暗红旗帜；应用图标与界面徽章统一。

可先在「汉化工坊 → 汉化管理与启动」导入其他汉化或添加已有汉化，保存多文件方案，预览并应用切换，然后从软件启动当前目录的游戏。旧包保留备份；独立汉化自动加载内置中文地图字体。管理第三方 ZIP 不会将其译文或脚本并入独立词库。

独立汉化 **0.3.0-rc.2** 从软件启动时，地图、任务和对话统一显示中文地名；从 Steam 或游戏 EXE 直接启动时，三处统一显示英文，正文仍为中文。请先生成并应用一次新版包。英文原始数据和存档保持不变，关闭软件不会影响已启动的游戏，下次直接启动仍默认英文；旧存档已保存的中文地名不会自动恢复。

新版不再覆盖「显星显属性带评价」的招募界面，并随包提供公开的 Modding Script Hooks 框架。该 MOD 原文件保持不变；本机文件副本的切换，以及显星 MOD 启用和停用两种招募界面均通过离线检查。种子筛选、更新事务、界面和汉化的回归检查均在不启动游戏的环境下进行。原有 7,723 个地名的地图与对话检查仍仅为离线验证。发布前检查与已知问题见[版本说明](app/releases/0.3.0-rc.4.md)。

运行与验证、汉化范围、打包方式详见 [app/README.md](app/README.md)。

```powershell
cd app
pip install -r requirements.txt
python main.py
```
