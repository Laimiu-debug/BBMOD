# BBMOD

《战场兄弟》1.5.2.3 的 Windows 桌面管理器与 MOD 资源合集。

## 下载测试版

[下载 BBMOD](https://bbmod.site/downloads/windows/) · [版本说明](https://bbmod.site/downloads/) · [独立汉化包](https://bbmod.site/mods/22c174ed-fc9d-4dbb-9642-44831ce694e8/)

网站当前发布为 **0.3.0-rc.24 测试版**，配套独立汉化 **0.3.0-rc.7**。单文件 EXE 内置独立汉化词库与普通 MOD 显示资源，无需安装 Python。请自行安装受支持的 Steam 原版 1.5.2.3 及相应 DLC；首次运行后选择游戏目录。已有可用汉化时可直接启动；需要新版独立汉化时，在「汉化管理」导入网站提供的汉化 ZIP 并应用，无需再次生成。第三方汉化和显星 MOD 需要另外安装。

rc24 汇总装备表格与图标、部分红装鉴定修复、启动状态和当前汉化引导、种子批量分享与快捷复制。独立汉化通读 15,819 条中文文本及随机分支，修订 634 条。详见 [rc24 说明](app/releases/0.3.0-rc.24.md) 与 [逐句审校记录](app/docs/localization-sentence-review-20260919.md)。本轮未启动游戏，实际画面及全部 MOD 组合仍待验收。

rc15 在种子远征「地图与港口」增加南北港、竞技场港筛选，可叠加数量条件并自动保存。详见 [rc15 说明](app/releases/0.3.0-rc.15.md)。

rc14 新增装备百科：悬停红装自动显示独立对比小框，跟随鼠标并避开游戏原属性框，支持自定义暂停快捷键和背景透明度。还包含种子删除与恢复、设置页静默更新、桌面反馈与建议；官网种子广场保留原样式并增加分页。详见 [rc14 说明](app/releases/0.3.0-rc.14.md)。脚本与桌面联调已验证，真实游戏悬停仍需玩家验收。

rc12 新增侧栏「设置」：选择本机中文字体，预览并应用 10–18 号文字，重启后保留；默认字号已加大。支持恢复推荐、字体缺失回退，以及大字模式的表格行高和页面滚动。详见 [rc12 说明](app/releases/0.3.0-rc.12.md)。

rc10 包含指定红武器筛选：50 种武器、最低数量和可选的伤害／穿甲品质，可选择「只找红装」独立搜索；同时删除旧注入启动器、DLL 和构建入口，网站已撤回旧注入版下载。详见 [rc10 说明](app/releases/0.3.0-rc.10.md)。汉化包的实机地图抽查及恢复记录见 [rc.8 说明](app/releases/0.3.0-rc.8.md)。

## 管理器

rc10 包含种子持续进度、本地保存和匿名「分享给兄弟」。配套 Hub 0.3.1 提供 [种子广场](https://bbmod.site/seeds/) 与筛选、访客欢迎编号和后台访问统计。详见 [rc.7 说明](app/releases/0.3.0-rc.7.md)。

- **营地总览**：游戏定位、DLC、MOD 依赖与上次启动日志诊断。
- **MOD 军械库**：仓库浏览、安装、启用、禁用与方案保存；在线军械库可连接自托管网站、下载校验、检查前置与声明冲突、更新备份及恢复上一版。
- **汉化管理**：展示当前启用的包与版本，支持导入、切换和备份；高级制作工具可编辑 15,816 条文本，另有 3 条动态提示。最新一轮已逐句通读并修订 634 条。自有显示适配器与 ZIP 构建，不依赖狐狸汉化文件；新版游戏内显示尚待实机验收。
- **种子远征**：按所选起源自动新建战役，可设置战斗／经济难度和资金；属性、人物特质与地图筛选，58 种开局特质支持必选、排除和全部／任意匹配。实时结果、一键复制、弹幕文案、TXT 导出与可恢复的文件会话。
- **装备百科**：软件内离线浏览 491 个装备条目，中英文搜索、分类筛选、属性排序及详情；其中 94 种红装提供随机范围。「装备鉴定」为独立页签，读取游戏悬停并对照实际属性。
- **反馈与建议**：桌面免登录提交，管理员后台查看与处理；支持失败重试与回执。
- **版本与更新**：官网优先，后台下载校验，正常退出时静默替换，也可主动重启更新。rc.13 及更早版本使用旧 GitHub 源，需要从网站下载 rc.14 一次。
- **设置**：固定在侧栏最下方，集中字体、字号、手动检查及自动更新选项；设置保存在本机，独立于游戏汉化。

界面采用手绘营地插画、金属盾徽、木质底板、卷轴面板与暗红旗帜；应用图标与界面徽章统一。

可在「汉化管理」导入其他汉化或收录已安装汉化，保存多文件方案，预览并应用切换，然后从软件启动当前目录的游戏。旧包保留备份；独立汉化自动加载内置中文地图字体。管理第三方 ZIP 不会将其译文或脚本并入独立词库。

启用独立汉化 **0.3.0-rc.7** 后，从 BBMOD、Steam 或游戏 EXE 启动均通过普通 MOD 显示中文地名。仅更新桌面软件无需重做当前汉化；要使用新版译文，可导入官网新版包并应用。原始英文名称和存档字段不改写；旧存档已保存的中文地名不会自动恢复。程序不再调用旧中文注入组件。

新版不覆盖「显星显属性带评价」的招募界面，并随包提供公开的 Modding Script Hooks 框架。7,723 个地名的词典检查全量离线执行，实机只对可见地点抽查。测试过程中的 MOD、存档备份和恢复校验，以及第三方依赖报错的边界见 [地图实现记录](app/localization/MOD_MAP_DISPLAY.md)。

运行与验证、汉化范围、打包方式详见 [app/README.md](app/README.md)。

```powershell
cd app
pip install -r requirements.txt
python main.py
```

## 社区 MOD 分发网站

`web/` 提供可在 Ubuntu 上部署的军械库：公开浏览与下载、作者上传和历史版本、管理员账号管理与下架、匿名种子分享与分页筛选、反馈与建议、游戏百科，以及浏览器访客编号和访问统计。作者使用管理员分配的账号，首次改密后可直接发布。[在线网站](https://bbmod.site/) 当前为 Hub 0.3.4，通过既有网关提供 HTTPS。站点与桌面软件共用目录、更新与反馈 API；源码包不包含预设账号或上传数据。部署步骤与备份说明见 [网站文档](web/README.md)。部署源码包为 `output/deployment/desktop-api-20260918/BBMOD-Hub-0.3.4.tar.gz`；GitHub 旧发布附件尚未更新。
