# BBMOD

《战场兄弟》1.5.2.3 的 Windows 桌面管理器与 MOD 资源合集。

官网已迁移至 **https://bbmod.com**，网站、API 和下载由海外服务器直接提供。桌面管理器当前版本为 **0.3.1**；rc.36 及更新版本可在软件内检查更新，更早的旧官网版本请从新官网手动更换最新版。

**第一次使用？** 查看 [官网图文使用说明](https://bbmod.com/guide/)（含 PDF 下载，已更新至阿飞 v0.27.4）。仓库保留 [Markdown](BBMOD新手使用说明.md)、含内嵌截图的 [离线网页版](BBMOD新手使用说明.html) 和 [PDF](output/pdf/BBMOD新手使用说明.pdf)，方便发给朋友。升级阿飞主包后请新建战役。

## 下载当前版本

当前版本为 **0.3.1**，详见[版本说明](app/releases/0.3.1.md)：修复设置保存、损坏配置启动和 MOD 并发修改问题。版本固定使用三段编号，打包不自动改号，规则见[版本约定](app/docs/versioning.md)。可在「设置 → 检查更新」获取新版，自动检查沿用 6 小时间隔。独立汉化继续使用 **0.3.0-rc.9**，无需重新生成汉化包。

[下载 BBMOD](https://bbmod.com/downloads/windows/) · [版本说明](https://bbmod.com/downloads/) · [独立汉化包](https://bbmod.com/mods/22c174ed-fc9d-4dbb-9642-44831ce694e8/)

单文件 EXE 内置独立汉化词库与普通 MOD 显示资源，无需安装 Python。请自行安装受支持的 Steam 原版 1.5.2.3 及相应 DLC；首次运行后选择游戏目录。已有可用汉化时可直接启动；需要新版独立汉化时，在「汉化管理」导入网站提供的汉化 ZIP 并应用，无需再次生成。第三方汉化和显星 MOD 需要另外安装。

历次版本的改动见 [app/releases/](app/releases/)，例如 [rc.33 疑似闪退报告](app/releases/0.3.0-rc.33.md)、[rc.29 共享 MOD 方案](app/releases/0.3.0-rc.29.md)、[rc.25 人名与属地语序修复](app/releases/0.3.0-rc.25.md)、[rc.24 汉化逐句审校](app/releases/0.3.0-rc.24.md)（另见[逐句审校记录](app/docs/localization-sentence-review-20260919.md)）和 [rc.8 汉化实机地图抽查](app/releases/0.3.0-rc.8.md)。

## 管理器

- **营地总览**：游戏定位、DLC、MOD 依赖与上次启动日志诊断。
- **MOD 军械库**：仓库浏览、安装、启用、禁用与方案保存；在线军械库可连接自托管网站、下载校验、检查前置与声明冲突、更新备份及恢复上一版。
- **方案管理**：整理本地 MOD 组合，直接搜索和分页浏览网站方案，预览变更后下载并应用；保存分享链接供重复复制。
- **汉化管理**：展示当前启用的包与版本，支持导入、切换和备份；高级制作工具可编辑 15,816 条文本，另有 3 条动态提示。最新一轮已逐句通读并修订 634 条。自有显示适配器与 ZIP 构建，不依赖狐狸汉化文件；新版游戏内显示尚待实机验收。
- **种子远征**：按所选起源（含阿飞远征团）自动新建战役，可设置战斗／经济难度和资金；属性、人物特质、地图港口与指定红武器筛选，58 种开局特质支持必选、排除和全部／任意匹配。实时结果、一键复制、弹幕文案、TXT 导出与可恢复的文件会话；本地保存的种子可匿名分享到官网[种子广场](https://bbmod.com/seeds/)。
- **装备百科**：软件内离线浏览 491 个装备条目，中英文搜索、分类筛选、属性排序及详情；其中 94 种红装提供随机范围。「装备鉴定」为独立页签，读取游戏悬停并对照实际属性。
- **反馈与建议**：桌面免登录提交，管理员后台查看与处理；支持失败重试与回执。
- **版本与更新**：官网优先，后台下载校验，正常退出时静默替换，也可主动重启更新。rc.36 之前的旧版 EXE 先从 `https://bbmod.com` 手动更换最新版，之后使用官网更新。
- **设置**：固定在侧栏最下方，集中字体、字号、游戏错误报告、手动检查及自动更新选项；设置保存在本机，独立于游戏汉化。

界面采用手绘营地插画、金属盾徽、木质底板、卷轴面板与暗红旗帜；应用图标与界面徽章统一。

可在「汉化管理」导入其他汉化或收录已安装汉化，保存多文件方案，预览并应用切换，然后从软件启动当前目录的游戏。旧包保留备份；独立汉化自动加载内置中文地图字体。管理第三方 ZIP 不会将其译文或脚本并入独立词库。

启用独立汉化 **0.3.0-rc.8** 及更新版本（当前 rc.9）后，从 BBMOD、Steam 或游戏 EXE 启动均通过普通 MOD 显示中文地名。仅更新桌面软件无需重做当前汉化；要使用新版译文，可导入官网新版包并应用。原始英文名称和存档字段不改写；旧存档已保存的中文地名不会自动恢复。程序不再调用旧中文注入组件。

新版不覆盖「显星显属性带评价」的招募界面，并随包提供公开的 Modding Script Hooks 框架。7,723 个地名的词典检查全量离线执行，实机只对可见地点抽查。测试过程中的 MOD、存档备份和恢复校验，以及第三方依赖报错的边界见 [地图实现记录](app/localization/MOD_MAP_DISPLAY.md)。

运行与验证、汉化范围、打包方式详见 [app/README.md](app/README.md)。源码运行只需 `requirements.txt`；测试安装 `requirements-test.txt`，打包安装 `requirements-dev.txt`。

```powershell
cd app
pip install -r requirements.txt
python main.py
```

## 社区 MOD 分发网站

`web/` 提供可在 Ubuntu 上部署的军械库：公开浏览与下载、作者上传和历史版本、管理员账号管理与下架、匿名种子分享与分页筛选、反馈与建议、游戏百科，以及浏览器访客编号和访问统计。作者使用管理员分配的账号，首次改密后可直接发布。[官网](https://bbmod.com/) 对应 Hub 0.3.7，已迁移至海外服务器，保留原账号、作品和历史数据。站点与桌面软件共用目录、更新与反馈 API；源码包不包含预设账号或上传数据。部署步骤与备份说明见 [网站文档](web/README.md)。迁移使用正在运行的生产代码及其一致数据备份，GitHub 旧发布附件未同步此迁移。
