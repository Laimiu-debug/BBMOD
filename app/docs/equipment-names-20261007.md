# 装备名称与游戏文本对齐（2026-10-07）

本轮修复桌面装备百科、悬停鉴定和种子筛选中的装备名称，并同步网站具体装备类型页的命名规则。桌面修复已随 0.4.1 于 2026-10-07 打包发布；网站百科译文本轮仍只保存在本地，未部署。

后续按用户要求补齐测试环境，原六个模块由 97 通过、6 跳过变为 103 通过、0 跳过。完整桌面回归及必要补测共 718 通过、0 跳过；EXE 自检和旧版更新器升级验证通过，详见[环境记录](test-environment-20261007.md)与[发布记录](../../web/deploy/deployment-desktop-0.4.1-localization-0.3.1-2026-10-07.md)。以下保留最初审校阶段的验证范围。

## 名称依据与显示规则

直接静态读取本机原版 1.5.2.3 的 `data_001.dat`，核对 94 类红装的 `NameList`、共享名称池及父类命名逻辑。这些装备的具体名称会随机生成，玩家也可以改名，不能把“红＋类型名”或某一个随机名字当作整类装备的固定名称。

- 装备鉴定以读取器收到的游戏当前名称为标题，保留玩家自定义名称；下方另列基础类型。仅在名称为空时回退到类型名。
- 离线百科按基础类型或外观列出装备，“红装”显示在品质列。详情说明随机命名规则，并提供名称示例。
- 搜索支持原版名称池的中英文成分；同一个名字可能对应多个类型，会显示所有匹配项。例如“夜幕披衣”对应黑色皮甲和贵族锁甲。
- 种子武器筛选复用同一份类型目录；结果使用“巨剑（红装）”等形式，避免维护另一套不一致的装备名称。
- 真正表示颜色的“红”保留，例如“红白盾”“红金饰带盔”。

## 修正示例

| 旧显示 | 新类型名 | 原因 |
| --- | --- | --- |
| 红红金头带盔 | 红金饰带盔 | 去除品质前缀，保留配色并校正外观描述 |
| 红红白盾 | 红白盾 | 去除重复品质前缀 |
| 红金羽盔（缠头盔脚本） | 黑金缠头盔 | 修复按文件顺序套名称造成的错配 |
| 红黑金缠头盔（金羽盔脚本） | 金羽盔 | 修复同一处错配 |
| 红兽人斧 | 裂颅斧 | 对齐对应普通装备脚本的名称及现有游戏译文 |
| 红地精重弓 | 强化荒野短弓 | 对齐原版名称，补上原先遗漏的子目录来源 |
| 红双手钉锤（尖刺钉锤） | 双手尖刺钉锤 | 区分不同武器类型 |

逐项来源登记在 [names.json](../data/item_inspector/names.json)，以装备 ID 和脚本路径定位，不再依赖文件排序。45 类武器使用对应普通装备的原版名称，另外 5 类使用已审定的武器种类通称；护甲、头盔和盾牌使用经核对的外观描述。这些类型标签不冒充随机生成的实物名称。

94 类装备包含 1,331 个名称池成分，中文取自当前已审定游戏词库；该数量包括不同装备共用的名称。生成时要求每个名称成分都有译文，并检查装备 ID 与来源路径一致。

## 验证

- 独立复核原版 CNUT、名称池顺序及当前词库，94 类全部匹配。
- 鉴定目录 94 项、完整装备目录 491 项的数值、运行标识、非语言字段和原版脚本来源哈希均与修改前一致。图片及其对应关系未变，图片清单仅更新目录校验值。
- 两个名称刷新函数重复执行结果一致；调换来源登记顺序不会交换装备名称，错误的脚本对应关系会被拒绝。
- 桌面相关六个测试模块共 **97 项通过、6 项跳过、0 项失败**。跳过项依赖当前缺少的原版反编译目录、游戏 UI 提取夹具或离线 Squirrel 解释器，不计为通过。
- 离线界面检查通过搜索、筛选、排序、详情及空结果状态；检查 1360×880 和 1080×720 两种窗口，名称与品质分列显示正常。

完整核验与逐项名称变化见 [验证记录](equipment-names-20261007-validation.json)。本轮没有启动游戏进行悬停实测，没有安装读取 MOD、修改游戏目录或替换已发布 EXE；也未宣称重新构建了原版数值目录。

从仓库根目录运行桌面回归：

```powershell
app/.venv/Scripts/python.exe app/tools/run_desktop_tests.py test_item_inspector.py test_inspector_ui.py test_seed_weapons.py test_seed_presentation.py test_seed_live_logs.py test_equipment_catalog.py
```

仅更新语言元数据时，可依次运行 `tools/build_item_catalog.py --refresh-names` 和 `tools/build_equipment_catalog.py --refresh-names`。数值仍取自已有核验目录；完整重建仍需要原版反编译输入。刷新后须核对图标对应及文件哈希，再同步图标清单中的目录校验值。

网站命名同步及其独立测试见 [网站审校记录](../../web/docs/wiki-equipment-localization-20261007.md)。
