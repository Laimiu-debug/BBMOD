## 修复和使用约束

- 铠甲标识：移除 UI 文件夹内夹带的旧 V2 完整包，避免被管理器解出并重复注册。
- EIMO：快速切换道具拆包，能够独立启用、停用、卸载；不再产生乱码中文内层文件名。
- 达库尔献祭：RAR 转为游戏可直接加载的 ZIP，源脚本字节保持一致。
- 军团外套：1.5.2024 明确写为解释器原先实际读取的 1.5；移除与源码同路径的编译入口。
- 骨板显示器：移除两份与源码同路径的编译脚本。
- 无限竞技场：原编译覆盖会被狐狸汉化源码遮住。现基于合集对应汉化脚本，仅删除原 MOD 相同的七处竞技场冷却刷新调用，其他源码字节保持不变；不修改竞技锦标赛脚本。
- 预载清单：新版管理器将基础资源与启用 MOD 的清单自动合并，停用、卸载、恢复方案时重建。请通过管理器操作，不要把整个合集直接全部复制到 data。
- 两套完整汉化二选一；轻度显星与显星显属性带评价二选一。管理器会阻止同时启用。
- 先安装 Modern Hooks、MSU；Modding Script Hooks 由狐狸汉化或 BBMOD 独立汉化提供。可以与所需功能包一起多选安装，整批检查通过才会写入。
- 编译版脚本已检查字节码结构与载入，不代表逐条证明游戏内逻辑；作弊、起源和影响种子的 MOD 按需选择。

## 复现与来源

生成：`python app/tools/prepare_fox_collection.py --source <原合集目录> --output <新的适配目录>`。原包必须与随附审核哈希一致，工具拒绝覆盖用户修改后的输出。

校验：`python app/tools/audit_fox_collection.py --collection <适配目录> --sq <sq.exe> --bbsq <bbsq.exe> --output <报告.json> --lifecycle`。使用临时游戏目录，不启动游戏。

Squirrel 与字节码工具来自 [Adam Milazzo 的 Battle Brothers mod kit](https://www.adammil.net/blog/v133_Battle_Brothers_mod_kit.html)。测试仅编译／读取 MOD，不执行其中游戏回调。

原始第三方 MOD 的作者与许可保持原样。本次未上传、发布这些第三方资源。
