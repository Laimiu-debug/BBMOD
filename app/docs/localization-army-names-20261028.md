# 军队及佣兵团名称修正 · 独立汉化 0.3.3

2026-10-28，本地修复包完成下述验证后，经用户明确要求发布到[原有 BBMOD 汉化作品](https://bbmod.com/mods/22c174ed-fc9d-4dbb-9642-44831ce694e8/)。发布 ID 为 `ce888756-91b8-4a66-820f-2bb17da5408c`，公开完整下载与本地成品逐字节一致。尚未安装到用户游戏，未做游戏内画面复核；赌场兄弟 0.1.2 包和桌面客户端版本保持原样。

## 改动

- 57 个原版佣兵团名以明确的名称表匹配。`Iron Ravens (12)` 显示为“铁鸦 (12)”，`Bulwark (12)` 显示为“壁垒 (12)”，括号、人数与外侧空格保留。
- 原版领主部队的 `地点 + Company` 译为“地点军队”，区别于独立佣兵团；涉及14个原版脚本、15处实际常量。旧档的“地点 战团”在已知城镇名范围内作显示转换。
- 南方已知城邦的 `Regiment of 城邦` 和旧“军团：城邦”统一显示为“城邦军团”。
- 单独的 `Company` 界面标签仍是“战团”，不会被去掉首空格后的军队后缀覆盖。未知自定义名称、可编辑输入框与明确关闭翻译的节点保持原样。

`Bulwark` 同时出现在原版佣兵团名和山地名列表，编译器共用一个常量。此前的检查称它为原生词库漏译，深入检查后确认是保留原始地名策略造成的共用常量限制。本次在显示层补齐它，不直接替换该常量，不改变山地原名、旧存档身份或地图生成随机序列。
