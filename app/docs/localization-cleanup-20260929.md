# 汉化卸载与方案残留修复

状态：已随 BBMOD 0.3.0-rc.34 打包发布，见[发布记录](../../web/deploy/deployment-localization-cleanup-rc34-2026-09-29.md)。下文保留源码修复阶段的验证记录。

停用只移动 ZIP，保留文件和方案以便重新启用。原先军械库卸载只删除安装文件和在线安装记录，没有同步汉化方案；汉化页还固定显示没有实际内容的 BBMOD 选项，且没有删除旧方案的入口。

## 当前行为

- 在军械库卸载汉化的最后一份安装副本时，同一事务移除关联汉化方案。多文件方案整体移除，其他已安装文件保留，避免应用残缺方案又装回刚卸载的文件。
- 同名安装副本或内容一致的改名副本仍存在时保留方案；重新启用同名、同内容的停用包时移走重复副本，不同内容的旧包继续保留。
- 卸载广播刷新汉化页，移除已失效的方案选择并保存“保持当前汉化”，不再误提示重新安装。无已保存或已启用 BBMOD 包时隐藏空占位。
- 选中已保存方案后出现“删除方案”，一次确认后清理方案名称，可处理旧版本已卸载留下的记录。保留安装文件、原包、汉化库副本和恢复备份；删除当前方案也不影响当前游戏启动。
- 游戏运行、种子远征、其他文件操作或未恢复的操作期间，不允许删除方案；卸载遇到未恢复汉化切换时停止。

## 验证

- `python -X utf8 tools/run_desktop_tests.py`：195 项通过，10 个模块均通过。覆盖启用/停用卸载、最后副本、改名副本、多文件方案、无关草稿保留、写入失败回滚、中断恢复、选择持久化及启动反馈。
- `python -X utf8 tools/check_localization_cleanup_ui.py`：真实 Qt 主窗口内走通“汉化页停用 → 军械库卸载 → 汉化页自动刷新”和“删除旧方案”。1360×880、1080×720 两种尺寸验证 5 种状态，截图及记录位于 `build/review/localization-cleanup/`。已检查旧方案删除按钮及卸载后空列表截图。全部使用临时游戏、临时用户配置，未启动游戏或修改用户安装。
- `git diff --check` 通过。
- 原有 `check_localization_manager_ui.py` 在 1080×720 下的“应用方案按钮必须整体位于窗口”检查失败；使用提交前版本的汉化管理界面也复现相同位置 `(814, 686, 102, 36)`。这是已有布局/检查问题，本次未将该旧脚本记为通过；本轮入口与跨页流程使用上述专用脚本验证，窄窗下保留原有滚动。

用户操作保持军械库原有的一次卸载确认，无额外清理步骤。已有残留记录需选中方案、点击删除、确认一次；普通成功反馈显示在原页面，无成功确认弹窗。
