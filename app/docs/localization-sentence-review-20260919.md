## 主要修订

- 属性与机制名称统一为“意志、近战命中、远程命中”，明确“结束行动”和“结束回合”的区别，统一士气档位、武器、职业和势力称谓。
- 修复收到伤害、淬毒、吸血、疲劳恢复、誓言剩余时间、竞技场战绩和换装行动点等拼接语序。
- 改善委托和事件中的生硬直译、指代不明、习语误译和词语搭配，保留情节与人物语气。
- 地形作为名词片段代入对白，距离作为远近描述，避免“北边的在森林中”和“走很近”等病句。
- 南方人物按“职位＋姓名”显示；支持英文、中文及混合旧称呼，仅匹配已知姓名与职位，不写回存档或改动随机姓名池。
- 装备随机名称中的 Old、Whip 分别为“古旧、长鞭”，与人物特质“年迈”和技能“鞭击”分开；沙漠、北境的装备后缀也按装备场景处理。
- 原版两段对话的颜色控制符、一个随机分支缺失的外围括号已作精确修复；骰子输局中误写“二十”的一处文本改为“二十五”，与原版实际扣款一致。三个排版例外均限定完整英文哈希和已核对的标记序列，其余校验不放宽。
- 软件装备表格、红装表和种子特质说明同步更新；装备数值、来源事实和特质互斥规则不变。

## 验证与边界

词库通过变量、数字、分支分隔符和排版检查。三个已核对的原版排版错误按上述限定例外处理，原文匹配键与游戏指令不变。最终 ZIP 的 634 条修订已全部核对，覆盖 370 个文件、768 处源文本使用位置；四条装备场景译文也已核对。

Python 全套回归 337 项通过，最后的打包修复另有 22 项相关回归通过。最终包检查了 2,281 个原版脚本、19,329 个函数，游戏指令保持不变；实际字节码离线执行通过 802 条整句输出及 159 条技能拼接输出检查。12 种结算、10,222 个原有称呼形式与 128,064 个南方姓名职位组合均通过检查。桌面 EXE 已验证内置资源一致，并在项目目录之外独立自检通过。

原版 UI 解析器对修复涉及的 20 个分支验证通过。地形与距离另作 10,980 个非空组合的静态代入检查；原版空地形或失效目标的退化值单列在报告中，尚未确认真实场景可达，未借语言修订改变游戏流程。

**本轮没有启动游戏。** 离线检查不等同于真实游戏排版、剧情触发或全部 MOD 组合验收。当前为本地预览，未发布官网。
