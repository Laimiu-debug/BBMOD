相对于 BBMOD 官网当前公开版本，方案中的阿飞远征团主 MOD 已落后：实际为 **v0.23.1**，官网最新公开版为 **v0.24.0**。方案显示的 `27` 是脚本内部注册版本，不是对外发行版本号。

四个狐狸合集组件的游戏运行文件与官网最新公开包逐字节一致；官网包仅增加来源和校验说明。独立汉化文件完全一致，装备鉴定的读取组件也与当前源码一致。

本次仅核查，不修改线上方案、发布记录或本机游戏。这里的“最新”以 BBMOD 官网公开目录为基准，不声称已核查所有第三方原作者站点的最新版本。

## 阿飞起源的版本边界

- 方案里的文件 SHA-256：`0cc0b6bacc8eddf0321d690da5ca1a666e52c1df55ec631545ad96d3650fd0d8`，大小 2,253,277 字节；与阿飞项目的 v0.23.1 发布记录一致。
- 官网最新公开文件 SHA-256：`109dbe4d0df3c1de467d70e3853c768bea840b006631a0d6e2afaff3ccd89b8b`，大小 2,230,474 字节，发行版本 v0.24.0。
- 当前本地阿飞工程另有 v0.25.0，`VERSION` 和 README 均标明这一版本；核查时官网公开目录仍为 v0.24.0。不要把本地开发包直接当作已公开的方案版本。
- v0.23.1 → v0.24.0 的包内差异为 18 项文件变化、3 项新增、4 项删除，涉及蓝队剧情、人物数据、美术及修复内容。
- v0.24.0 的公开说明要求按新战役使用，不保证旧存档兼容。修改共享方案会影响以后重新应用它的玩家，应在方案介绍中明确这一点。

## 建议

若要让方案与官网当前公开包保持一致，应将阿飞远征团更新为 v0.24.0，修正独立汉化的名称及版本，并可将四个狐狸组件替换为官网带来源说明的同内容发行包。装备鉴定读取组件保留即可。

若目标是使用本地 v0.25.0，应先单独完成该版本的发布，再更新方案；这与本次版本核查是不同的操作。

## 核查方法与证据

读取官网方案清单、公开 MOD 目录和管理器发布接口，下载涉及的 12 个不同 ZIP 文件，分别核对大小、SHA-256 与 ZIP CRC。对同名 MOD 进一步按包内路径逐文件比较内容，避免把重新压缩或附加说明误判为功能升级。没有运行这些下载包中的脚本，也没有启动游戏。

装备鉴定对照 `app/core/inspector_mod.py` 中的组件版本、`app/data/item_inspector/bridge.nut` 和 `hover.js`，并验证包内文件清单与摘要。检查的是读取组件，不是整个桌面软件版本。

本地证据保存于 `app/build/profile-version-audit/`：`profile.json`、`catalog.json`、`desktop.json`、`result.json`，以及经过校验的 ZIP 副本。版本映射另据 `G:/CODE/afei-xcpedition/docs/releases/publication-0.23.1.md` 和 `docs/releases/v0.23.1.md`。
