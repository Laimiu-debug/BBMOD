# 离线地图解算与跑商预览

入口为「种子远征 → 离线地图与跑商」。也可从「我的种子」预览所选种子。
运行时只输入区分大小写的十位种子，不启动游戏、不读取游戏目录、不加载用户 MOD。
当前规则固定为原版 1.5.2.3、全部官方 DLC；修改地图生成规则的 MOD 不在此配置的对照范围。

## 实现与验证范围

`core/worldmap/engine.py` 调用独立的 `worldmap.exe`。它使用自行实现的随机数、六边形地块与寻路服务，
在 Squirrel VM 中执行固定版本的原版地图规则。保留 32 位整数和浮点运算语义。
运行组件包含程序、引导脚本与规则包，可整体复制到其他目录运行，无需游戏 EXE 或 DLL。

对照的是原版 `worldmap_generator.fill` 的完整静态地图：23,800 地块的地形、战术地形、子区域、区域及道路方向，
以及城镇、建筑、附属设施、产出、连接、基础价格系数和区域名称及落点。
页面继续执行开局势力创建、玩家落点和 2,000 轮原版势力模拟，独立生成营地、随机红装和南方城邦实际名称。
桌面 0.9.0 可选择全部 14 种官方起源，以及战斗、经济、初始资金各三档（27 种组合）；
默认仍为「农民民兵、全专家、全 DLC、无探索模式」。更换配置后点击「解算地图」重新生成，界面显示实际结果对应的开局配置。
从种子档案预览时会带入档案的起源和难度；配置缺失或自制起源会先提示，不以默认民兵结果代替。
商店库存和游玩中的事件、委托、刷新不属于开局解算结果。

开发采样器 `tools/capture_worldmap_reference.py` 才会使用游戏；它禁用测试战役存档、临时隔离 MOD，
结束后恢复原文件并核对哈希。正常解算器和地图页面不调用该采样器。

2026-10-22 的静态地图采样涵盖 `AbCdEfGhIj`、`ABCDEFGHIJ`、`46U2HMOORH`、`aaaaaaaaaa`、`ZZZZZZZZZZ`：
119,000 地块的 595,000 项字段、101 座城镇及 266 个命名区域均无差异。
十个完整开局的采样另外涵盖 `31S2a9H8KL`、`9WqXf2P7an`、`0123456789`、`0oO1lI2zZ3`、`abcdefghij`：
1,020 处营地和 183 件红装的位置、类型、名称、资源、强度、属性、随机词条记录，及玩家落点、城邦名称均无差异。
每个完整开局独立计算三次，耗时记录在 `build/offline-map/camp-validation.json`；静态地图报告为 `validation.json`。
当前完整解算的 30 次实测中位数为 2.91 秒，静态地图的最终复核中位数为 2.11 秒。
原版同配置的带只读探针开局阶段中位数约 7.13 秒，不含游戏启动；离线计时包含进程启动、JSON 输出和读取。
这组样本受机器负载影响，不代表所有种子的耗时保证。

组件会复制到 H 盘临时目录做脱离项目与游戏目录的完整解算、缓存和结果对照；记录在 `detached-check.json`。
二进制只导入 `KERNEL32.dll` 与 `msvcrt.dll`。完整原始证据与报告留在 `build/offline-map`；
压缩后的原版地图与营地夹具在 `tests/fixtures/worldmap`，文件名使用种子哈希以避免 NTFS 大小写冲突。

营地模拟使用原版人物、起源、势力、行动、地点和物品脚本；显示用的 NPC 对话头像在重新设种子前跳过。
0.9.0 通过完整人物和物资创建保持随机数顺序，替代先前仅支持民兵的对齐路径。
寻路将原版海洋的无穷大成本作为不可通行；负疲劳的半值舍入与游戏一致，`-16.5 → -17`。

## 路线与行情

地图支持缩放、平移、城镇选择、设施/地名图层、地形/商路视图。
城镇、特产、建筑、附属设施和地名复用 BBMOD 自带的已审核汉化与地名显示映射。
城镇详情展示规模、文化、港口、商店、生产设施，以及在此买入运往何处、从何处买入在此卖出的正毛利组合。
双击城镇按顺序加入路线；也可选商品生成产地到销地的预览。支持撤销、反向、清空和 JSON 导出。
路线使用地形速度和实际道路连接做 Dijkstra 搜索；仅走道路时不会穿过道路断口。
基础行程按 `Speed=100 × GlobalMult=0.75`、道路速度倍数 1.5、每天 105 秒估算，
逐边距离使用原版地块世界坐标。未模拟夜间、队伍负重/特性、遭遇和海运。

行情使用原版十二类贸易品的基础价值、生产设施、城镇规模价格系数、文化和港口规则。
北方城镇按北方文化估算；关系为 50，无起源、随从与临时事件加成。
单件毛利是卖价估算减买价估算，价差率是毛利除以买价，未扣工资食物。
可输入计划采购数量与日开销，查看采购总额、回款、毛利和扣行程开销后的估算利润；数量不表示商品库存。

「营地红装」列出纯离线生成的武器、盔甲、头盔和盾牌，支持按类型、中文装备名或营地名筛选。
点击列表会把所在营地居中并标出，详情包含地图坐标、最近城镇方向与距离和具体属性；也可单击地图营地。
默认仅显示含红装的营地，勾选后可查看其他营地。重新解算或切换种子会清除旧营地选择。
装备基础名复用现有装备词库，原版随机专名在提示中保留；武器同时显示现有「伤穿优先 v1」实用分与 roll 品质。
部分营地名称中的随机称号不由种子唯一决定。同一掠夺者种子和难度连续三次原版开局，已观察到墓穴的 Great/Tyrant 称号变化，
而位置、势力、资源、强度、装备及人物数据相同；请按坐标和相邻城镇定位。对照报告单独记录此类已实证的文字变体，不忽略其他名称或战利品差异。
评分从原版物品生成的实际随机记录中读取两条词条，避免负疲劳取整后无法反推原 roll 的歧义。

## 开发与复现

在 `G:\CODE\bbmod\app` 执行：

```powershell
python -B tools/build_worldmap_runtime.py --compiler E:\mingw64\mingw64\bin\g++.exe
python -B tools/prepare_worldmap_rules.py --game 'F:\SteamLibrary\steamapps\common\Battle Brothers' --output build/offline-map/rules
python -B tools/capture_worldmap_reference.py --run-game --game 'F:\SteamLibrary\steamapps\common\Battle Brothers' --output build/offline-map/reference-new --no-checkpoints
python -B tools/validate_worldmap.py --capture build/offline-map/reference-release --repeats 3 --write-fixtures
python -B tools/capture_worldmap_reference.py --run-game --game 'F:\SteamLibrary\steamapps\common\Battle Brothers' --output build/offline-map/camps-reference-new --camps --no-checkpoints
python -B tools/validate_worldcamps.py --capture build/offline-map/camps-reference-final --repeats 3 --write-fixtures
python -B tools/package_worldmap.py --detached-check
python -B tools/preview_worldmap.py
python -B tools/preview_worldmap.py --view loot
```

规则包从本机官方资源一次性生成，不提交提取的原版脚本。原始采样、源码研究、构建与必要 QA 均在 G 盘，
通用临时目录和此机的地图缓存位于 H 盘。缓存键同时包含种子的大小写、规则清单、程序、引导与营地脚本、随机对齐模块的哈希。
纯地图与完整营地的缓存分开；完整营地的缓存同时区分起源和全部难度档位。
完整模式不会拿旧的空营地缓存冒充结果。种子或开局配置不符的营地记录会被拒绝。
损坏缓存会重新解算，取消计算会回收子进程。

Squirrel 上游版本为 v3.1，构建脚本固定下载 SHA-256，组件保留其版权许可。
`BBMOD_WORLDMAP_HOME` 可指定独立组件目录，`BBMOD_WORLDMAP_CACHE` 可指定缓存目录。
组件只有通过当前程序指纹的原版地图与营地两组对照后才能由打包工具生成。桌面 spec 会附带准备好的组件，
构建源码清单也包含组件哈希。

## 已发布集成

人物、特质及星位的独立筛选见 [独立人物解算](offline-brothers.md)，桌面 0.8.0 新增。

2026-10-22 已打包并发布桌面 0.7.0；入口为「种子远征 → 离线地图与跑商」。
地图字号默认 18 像素，可在 14–30 像素之间调整并保存；下拉列表按完整选项加宽，支持滚动到末项。
成品在项目和游戏目录之外运行自检，实际生成 19 座城镇、102 个营地和 10 件红装，并完成中文显示、武器评分和路线计算。

官网 0.4.1 在种子广场及种子详情添加「地图与跑商」入口，使用同一套规则的 Linux 解算器，
已完成 5 张完整地图、10 组营地与红装的原版参考对照。网站采用后台单任务解算、自动轮询、分级额度和缓存，
首次解算不会长时间占住网页请求；已缓存结果可直接读取。网站使用从 BBMOD 现有汉化词库导出的中文映射，
无需读取服务器上的游戏安装或玩家 MOD。

原版对照的本机冷解算中位数：地图 2.11 秒，完整营地 2.91 秒；服务器完整解算中位数 23.63 秒，
服务器读取缓存 0.37 秒。硬件、负载和网络不同，网页首次解算可能需要约一分钟。
完整桌面回归 902 项通过、2 项跳过；网站本地完整回归 229 项通过、1 项跳过，后台解算专项最终 15 项通过。
正式下载的完整 SHA-256 已与成品一致，客户端更新检查通过。详细部署与保留记录见 `web/deploy/deployment-atlas-2026-10-22.md`。
