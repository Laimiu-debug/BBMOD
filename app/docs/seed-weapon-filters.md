# 多武器筛选与红武评分

在「种子远征 → 营地红装」中，红装总数和武器要求可分别勾选、同时使用。武器要求最多 20 行，每行可搜索类型，设置件数、伤害品质、穿甲品质、实用词条评分与 roll 品质下限；不限项不参与。

- **全部满足**：每行是独立数量。一件武器只分配给一行要求，类别和具体武器重叠时会重新分配，避免贪心匹配漏掉有效种子。例如“任意远程 1 件＋标枪 1 件”需要两件不同武器。
- **任一满足**：满足任意一行的件数和所有门槛即可。例如标枪或巨剑任选一种。启用红装总数时，总数仍须满足。
- 同一行的伤害、穿甲与评分要求必须由同一件武器同时满足；0% 伤害或穿甲仍要求抽中对应词条。
- 不勾选武器要求时，已填的行会保留；旧的单武器设置自动迁移，不擅自启用过去未生效的总数要求。

红武评分显示在「我的种子」亮点与档案详情中，复制、导出详情也包含评分。有完整两条词条的历史日志自动获得评分，无需重新生成种子。详情保留原始属性信息。

## 评分模型：伤穿优先 v1

权重：伤害 100、穿甲 90、命中 85、破甲 70、技能减耗 55、疲劳减负 40、爆头 30、弹药 25、破盾 20。

**实用词条评分（0–100）**：两条 `权重 × (100 + 品质)` 贡献相加，再除以 `该武器可抽中词条的最高两项权重之和 × 2`，四舍五入。保留半数基础贡献以体现低 roll 词条仍有加成。不同词条组合可有不同实用分。

**roll 品质（0–100%）**：已抽中两条词条品质的平均值，四舍五入。疲劳负担的原始随机乘数越小，减负越多，因此方向取反；技能疲劳减耗方向保持收益越高品质越高。耐久是额外随机属性，不占这两条词条，不计分。

模型用于同类武器的词条参考，不模拟 DPS、不计角色特技与对手，也不表示胜率或不同武器类型的强弱。按原版 1.5.2.3 的 50 种红武词条池计算；未收录武器、词条不在原版词条池或记录不足时暂不评分，不会通过评分门槛。没有评分门槛的宽泛类型筛选仍可匹配未收录武器。

Python 展示与 Squirrel 筛选共用 Python 生成的权重和词条池配置；筛选不调用随机数、不修改装备，不改变种子生成序列。原有高级条件行保持兼容，新组合规则封装成一行，避免旧引擎外层 OR 导致总数和武器二选一。

## 预览与验证

`python -B tools/preview_seed_weapons.py` 打开独立界面预览，使用临时种子库和标明的示例记录。

`python -B tools/run_desktop_tests.py test_seed_weapons.py test_seed_weapon_rating.py` 分进程执行 UI、旧设置迁移、同件属性约束、多条件计数和实际 Squirrel 评分对照。评分对照覆盖所有原版武器的可选双词条组合及多组边界 roll。
