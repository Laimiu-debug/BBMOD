# BBMOD 0.3.0-rc.10

新增指定红武器筛选，并将地名汉化统一为普通 MOD 方式。

- 红武器可按 50 种具体类型或单手、双手、远程分类筛选，指定数量，以及伤害、穿甲词条的品质下限；支持只找红装。
- 配套独立汉化 0.3.0-rc.3：启用后从 Steam、游戏 EXE 或 BBMOD 启动均显示中文地名，存档中的原始地名保持英文。
- 删除旧注入启动器、DLL 及对应构建入口，普通游戏启动不再依赖这些组件。
- 修正选定游戏目录的启动路径，保留汉化冲突检查和切换备份恢复。

汉化已在 Steam 版 1.5.2.3 完成地图与角色界面实机验证；完整战役和所有第三方 MOD 组合尚未覆盖。红武器筛选已通过配置、Squirrel 执行和界面检查，本次未运行长时间实机刷种子。

汉化安装：游戏关闭时，用新版 mod_bbmod_zhcn.zip 替换 data 中的旧包，并停用其他重叠汉化；也可在汉化工坊生成并应用新版独立汉化。
