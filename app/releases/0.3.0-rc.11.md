# BBMOD 0.3.0-rc.11

新增「设置」页面，可自行调整 BBMOD 管理器的字体和字号。

- 点击左侧「设置」或按 Alt+5，选择本机中文字体和 10–18 号文字，预览后点击「应用字体」。全软件立即生效，重启后保留设置。
- 默认字号增大到 12 号（约 16 像素），同时放大表格、菜单和提示文字；可一键恢复推荐字体与字号。
- 字体不可用时自动使用内置中文字体。更改字体不会覆盖游戏目录、汉化方案或种子筛选设置。
- 表格行高和标题区域随字体调整，较长页面可以滚动查看；改善深色背景上状态文字的可读性。

字体设置仅作用于 BBMOD 管理器。游戏汉化继续使用普通 MOD 的 rc3 包，红武器筛选与原有功能保留。

已检查字体预览、即时应用、重启保留、缺失字体回退、保存失败恢复，以及不同字号下五个页面在 1080×720 和 1360×880 窗口中的操作可达性。
