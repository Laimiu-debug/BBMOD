# BBMOD 0.3.0-rc.13

本次更新主要修复启动报错，完善游戏目录识别与异常处理。

- 修复部分电脑首次打开软件时出现 `[WinError 87] 参数错误`、无法进入主界面的问题。
- 改进自动检测：遇到不存在、离线或无法访问的磁盘与 Steam 库时跳过，继续查找游戏。
- 改进失效目录处理：已保存的游戏目录被移动或无法访问时，仍可正常打开软件，通过「更换目录」重新选择。
- 找到有效游戏后停止扫描其他磁盘，减少不必要的访问；保留用户手动选择，不会静默切换到另一套游戏。

自定义安装目录可通过「更换目录」手动选择，例如 `E:\gaME\Battle Brothers1.5.2.3\Battle Brothers`。请选择同时包含 `win32\BattleBrothers.exe` 和 `data` 的游戏根目录。

配套独立汉化仍为 `0.3.0-rc.3`。现成的普通 MOD 汉化 ZIP 原样放入游戏 `data` 文件夹即可，无需解压；直接运行游戏 EXE 也能加载中文地图，不要求通过 BBMOD 启动。安装前请移出并备份其他重叠汉化包。

已通过 246 项回归测试，其中 18 项覆盖游戏目录与启动异常，并完成全新用户配置下的打包启动自检。本轮未进行真实游戏运行测试，修改版与第三方整合包的兼容性尚未验证。

现有校验规则保持不变：软件内生成汉化仍需受支持的原版 EXE；电脑上存在另一套 Steam 注册安装时，BBMOD 的启动保护会拒绝启动未注册的另一套目录。

升级时用新版 EXE 替换旧程序，已有用户设置会保留。内置自动更新器仍读取 GitHub，仅在网站发布的版本需手动下载。
