# BBMOD 0.3.0-rc.14

新增桌面装备百科、种子库管理、设置页更新和免登录反馈与建议。

- 装备百科：在页面安装或更新轻量读取 MOD，重启游戏；鼠标悬停红装自动显示独立对比小框，移开即隐藏。保留游戏原属性框全部内容；读取其实际边界，自动选择旁边有空间的位置，跟随鼠标并避开屏幕边缘。背景不透明度可调 50%–100%，默认 90%，文字保持清晰。窗口穿透鼠标、不抢游戏焦点，仅在选定游戏位于前台时显示。建议使用窗口化或无边框窗口，BBMOD 需保持运行。
- 自定义快捷键：直接录入组合键，默认 Ctrl+Alt+D，用于暂停 / 恢复自动悬停提示，无需每件装备按键。支持 Ctrl / Alt 组合及 F8 等功能键；占用冲突会保留原快捷键。旧读取 MOD 需在游戏退出后点击“安装 / 修复读取 MOD”更新。
- 范围对照：覆盖原版 1.5.2.3 的 94 种红武器、护甲、头盔和盾牌；保留英文底材名并对应 BBMOD 中文术语。逐项显示数值、随机范围和区间位置，校验伤害联动、两个词条规则，并还原护甲附件之前的数值。区间位置不是掉落概率或实战评分；未知、传奇或受 MOD 修改的装备不强行评级。
- 导航：装备百科与反馈与建议位于种子远征之后，设置固定在左侧导航最下方；Alt+1–7 按显示顺序排列。
- 游戏风格：鉴定页面与悬浮窗使用游戏背包式的暗色皮革、铁框和属性区间条。读取到装备后自动收起初次设置，保留随时展开的入口。
- 我的种子：将寻找新开局与种子管理分成两个页签，扩大列表。支持搜索、Ctrl / Shift 多选删除、回收站恢复；旧记录自动升级，重新搜索或重启后保留。删除只影响本机，已分享到网站的记录保留；重新导入旧日志不会复活已删除的种子。
- 软件更新：设置页可手动检查；优先连接 bbmod.site，官网不可用时尝试 GitHub。新版在后台下载并校验，默认于正常退出软件后静默替换，不自动重新打开；也可主动点击“立即重启更新”。保留旧程序备份，失败时回滚，不修改设置、游戏或存档。三个自动更新开关可单独调整。
- 反馈与建议：桌面内直接提交，支持可选联系方式、回执和失败重试；与官网管理员收件箱共用校验、限流和去重机制。只发送填写内容和软件版本，不上传日志或存档。
- 官网种子广场：默认每页 6 条，可选择 12 / 24 条；上下页码保留筛选与排序。保留原有浅色卡片样式。

本次为测试版。已验证离线 Squirrel 读取脚本、原版 UI 脚本回调、悬停显隐 / 心跳超时、桌面快捷键和日志至悬浮窗流程；本机隔离游戏启动在进入脚本前退出，实际游戏悬停和第三方 MOD 组合仍需玩家验收。汉化包版本保持独立，软件更新不会替换已安装汉化。
