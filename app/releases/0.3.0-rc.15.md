# BBMOD 0.3.0-rc.15

种子远征新增南北港与竞技场港筛选，方便寻找适合乘船往返和参加竞技场的开局地图。

- 在「种子远征 → 寻找新开局 → 地图与港口」勾选「南北港」或「竞技场港」，两项可同时使用。
- 南北港沿用生成器的地图分区：左上北港、左下南港各至少一座；中间港和东港不代替南北港。
- 竞技场港要求竞技场所在城邦同时有港口，其他城邦有港口不计入。
- 勾选项与港口、城镇、甲店数量门槛必须同时满足；未勾选表示不限。例如港口数量仍为 7 时，地图还须至少有 7 座港口。
- 地图筛选设置自动保存，重新打开软件后保留。适用于「人物 + 地图」「只找地图」「人物 + 地图 + 红装」；历史种子库与导入日志不按这些生成条件重新过滤。

本版为测试版。已完成离线脚本判定和桌面界面检查，实际游戏刷种仍待验收。汉化包继续使用独立的 0.3.0-rc.3，软件更新不会替换已安装汉化。
