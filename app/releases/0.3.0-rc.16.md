# BBMOD 0.3.0-rc.16 · 本地预览

装备百科默认打开软件内的装备资料表：491 个条目、94 种红装范围，中英文搜索、类型与品质筛选、数值排序、属性详情。查表无需游戏或读取 MOD。

- 装备名称旁增加原版物品图标，详情展示较大原图。436 个条目有物品图标，包含全部红装；55 个特殊条目无原版物品图标，明确说明。图标取自本机原版档案，保留来源、Overhype Studios 署名和文件哈希。
- 装备鉴定放在独立页签，结果可定位到表格。修复读取 MOD 对成员代理错误使用 `in` 检查造成空属性的问题；附件原始护甲 / 疲劳数值同步修复。
- 读取失败时清除上一件装备的旧结果，错误提示不再立即被计时文字覆盖。
- 读取 MOD 升为 v3，旧版显示更新提示。必须退出游戏后安装 / 修复，再启动游戏。不会自动关闭游戏或修改存档。
- 窗口图标使用多分辨率 ICO，设置稳定 Windows 应用标识，便于任务栏正确识别。

本版本尚未发布官网。装备表、图标、成员代理、安装备份及原版随机规则采用离线和桌面检查；真实游戏悬停与第三方 MOD 组合仍需实际验证。

本地验证：306 项测试通过、1 项真实进程往返按默认流程排除；94 种红装共 9,400 组随机规则验证通过；1360×880 / 1080×720 装备表及 28 个字体 / 页面组合检查通过。Windows 原生窗口的大、小及备用小图标句柄均可读取，ICO 含 16–256 像素的七种分辨率。
