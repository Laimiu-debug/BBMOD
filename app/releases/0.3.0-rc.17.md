# BBMOD 0.3.0-rc.17 · 本地预览

修复启动游戏后自动跳到汉化页、按钮仍提示再次启动的误导流程。

- 已应用的配置可从任意页面启动，保留当前页面；只有待应用或缺失的汉化方案才进入汉化管理，并在点击前显示“确认汉化方案”或“检查汉化配置”。
- 顶部和汉化页共用“正在启动 / 游戏运行中”状态。启动请求完成后继续等待实际进程出现，防止重复启动；游戏退出后恢复按钮。
- 识别从 Steam 等入口启动的游戏；游戏运行时暂不可切换汉化。启动报错或等待超时有明确提示，并可重试。
- 汉化管理与译文编辑的说明统一为新版 MOD 随游戏加载，无需第二次中文启动。
- 小窗口下，汉化管理的文件表独立滚动，隐藏的译文编辑页不再把应用按钮挤出窗口；保留大字号下控件所需高度。

包含 rc.16 的装备表格、原版装备图标和读取 MOD v3 修复。本版本尚未发布官网。流程验证使用隔离目录、模拟启动和进程状态，不会启动或关闭实际游戏。

本地检查：312 项回归测试通过，1 项真实进程往返测试按默认流程排除；1360×880 / 1080×720 下的管理、编辑、启动中、运行中及退出状态共 10 张界面检查通过；28 个字体 / 页面组合通过。检测过程不实际启动或关闭游戏，也不改动玩家的汉化配置。
