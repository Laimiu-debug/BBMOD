# BBMOD 0.3.0-rc.18 · 本地预览

汉化管理优先展示当前已启用的汉化，避免把已有汉化、待切换方案和制作工具混在一起，误导用户重复生成。

- 导航改为“汉化管理”，默认页显示当前启用的包；BBMOD 汉化展示实际包版本，不把下拉框中的待选方案当作当前汉化。
- 删除“更新后请重新生成”的通用提示。已有可用汉化时，日常启动和仅更新 BBMOD 软件均无需重新制作。
- 导入、收录和制作入口放在默认收起的高级操作中。“打开汉化制作工具”只进入编辑页，点击“制作并预览切换”才会制作新包。
- 待切换方案明确标记“尚未应用”。“取消切换，沿用当前”只取消选择，不改游戏文件；已应用方案不显示待切换提示。
- 手动安装了 BBMOD 汉化但没有方案记录时，仍显示已启用，说明无需重新生成。未检测到独立汉化包时，不武断认定游戏没有中文。

包含此前的启动状态修复和装备百科。本次只更新桌面软件，不替换玩家的汉化包。本版本尚未发布官网；实际游戏启动与游戏内显示不属于本轮验证。

本地验证：316 项测试通过，1 项真实进程往返测试按默认流程排除；12 张两种尺寸的状态 / 页面截图检查，以及 28 个字体 / 页面组合检查通过。回归覆盖实际启用文件与待选方案的区别、手动安装但未存方案、已保存但未启用、取消待切换不改文件、打开制作工具不构建或注册包。
