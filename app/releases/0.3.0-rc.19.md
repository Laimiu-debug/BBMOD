# BBMOD 0.3.0-rc.19 · 本地预览

「种子远征 → 我的种子」新增「一键分享全部」，无需逐个点击。点击时已有的完整种子及各自介绍会公开到种子广场，包括搜索隐藏的条目，不含回收站；之后新刷出的种子不会自动加入。

- 已成功分享的条目自动跳过。网站已有同一档案时沿用原链接和原介绍；种子码区分大小写，起源、版本与难度也是判重条件。
- 上传逐条排队，显示处理进度、成功 / 已存在 / 跳过 / 失败数量，以及等待倒计时。网站限流遵守 `Retry-After`；临时错误最多重试 3 次，再失败则暂停整批。
- 每条成功回执立即写入本地库，停止或重新打开软件后可再次点击继续未成功的记录。服务器要求的等待时间也会保留，重复点击不会跳过等待。
- 「停止上传」停止后续请求；已经发送的条目可能完成，回执仍会保存。「查看分享结果」显示失败原因并支持复制全部链接。单条已分享按钮改为「复制分享链接」。
- 不完整或无效档案跳过并记录原因，其他有效种子继续；网站整体不可用时暂停，不连续弹窗。隐藏的生成条件页面不再撑宽当前种子库。

本版保留 rc.18 的汉化状态引导、rc.17 的启动反馈，以及装备百科。尚未发布官网，无需重新制作汉化或更换游戏 MOD。

验证：桌面 333 项回归通过，1 项真实游戏进程往返测试排除；网站种子接口 9 项测试通过。界面覆盖批量等待、停止和大字体，28 个字体 / 页面组合通过。线上实际连续上传 2 条本机完整种子均返回 201，6 次重复上传均返回 200 且 `created=false`，未复现用户原来的第二次弹窗；因此不将根因认定为网站限流。验证结果位于 `build/review/seed-sharing/`。
