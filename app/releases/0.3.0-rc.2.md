# BBMOD 0.3.0-rc.2 · 测试版

**当前版本仍有未定位的中文启动问题，尚未完成新版游戏内验收。此版本用于试用和反馈，不作为稳定版推荐。**

## 下载与使用

1. 下载附件 **BBMOD.exe** 即可，无需下载源码或安装 Python。词库、字体、图标和启动组件已内置。
2. 自行安装受支持的 **Steam 原版 Battle Brothers 1.5.2.3** 及相应官方 DLC。
3. 打开软件，选择游戏目录，进入「汉化工坊 → 汉化管理与启动」，点击「生成 / 更新独立汉化」。
4. 选择独立汉化方案，核对切换列表并点击「应用方案」。仅打开 EXE 不会自动完成汉化安装。

显星、第三方汉化及其他玩法 MOD 需要另外安装。切换 ZIP 无法还原直接修改过的游戏本体归档。程序使用过程中请保留自己的存档备份。

## 本版内容

- 本体与官方 DLC 已提取的 15,629 条文本完成独立精修，包含 2,196 条地名；补充界面词条后共 15,815 条可编辑文本。
- 地名显示切换已经实现并通过离线检查：从 BBMOD 启动设计为地图、任务和对话统一显示中文地名；直接启动设计为保留英文地名。实际运行效果仍待验收。
- 汉化方案管理、MOD 启停、冲突预览及切换恢复。
- 种子筛选、TXT 导出、一键复制与弹幕文案；新版营地界面和图标。
