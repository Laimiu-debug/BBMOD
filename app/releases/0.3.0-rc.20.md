# BBMOD 0.3.0-rc.20 · 本地预览

「我的种子」不再需要先展开档案、再切换输出格式才能复制纯种子码。

- 搜索框旁常驻「复制种子码」，选中后直接点击；表格内 Ctrl+C 执行相同操作。
- 支持 Ctrl / Shift 多选，按列表顺序逐行复制，保留大小写，不包含搜索隐藏的记录；无选择时禁用按钮并保留剪贴板原内容。
- 展开档案后的旧复制按钮明确改为「复制文案」，表格内也可用 Ctrl+Shift+C。复制纯种子码不会改变文案格式或点选复制设置。
- 复制后按钮显示「已复制」，无需弹窗。重新选择或新结果到来不会主动替换剪贴板内容。

保留 rc.19 的一键分享和等待重试。本地预览尚未发布官网，不需要修改游戏文件或重新制作汉化。
