# BBMOD 0.3.0-rc.26

2026-09-25 已发布到官网，配套独立汉化仍为 0.3.0-rc.8；网站改动与线上下载已更新。

## MOD 管理

- 禁用保留文件，卸载删除所选安装文件并同步清理在线安装记录。已卸载条目退出已安装列表，仓库原包仍可重新安装。
- 已安装列表支持搜索、启用/禁用筛选和批量操作，按当前可见选中项执行并汇总失败原因。
- 方案先检查缺失文件和重复文件，再显示变更预览。文件变化通过持久化日志和校验备份执行，失败回退；异常退出后可恢复，恢复前阻止启动、汉化切换和种子远征。
- 本地 ZIP 与内嵌 ZIP 全部校验后安装，检查损坏、重复名、不安全路径和解压大小。真正的 RAR 需先解压再选择 MOD ZIP。

## 桌面与官网

- 在线军械库默认使用官网，自定义地址移入高级选项；无游戏目录和空列表提供下一步入口。
- 总览突出当前状态和新手三步操作，技术详情与普通诊断提示可折叠。新增依赖版本比较和前置搜索入口。
- 诊断报告自动遮盖常见个人路径、邮箱和 IP，可预览、编辑、导出 TXT 或手动加入反馈草稿；不会自动提交。
- 设置可启用网页联动：MOD 链接打开对应作品，种子链接经预览确认保存到本地；已经打开的管理器接收链接，不另开实例。
- 官网新增开始使用入口、三步指南、真实软件的演示数据截图；下载附近直接展示冲突、存档与种子影响。
- 新增 Windows 桌面回归工作流，统一版本元数据和使用说明。修复 Windows UTF-8 模式下进程检测输出解码问题，以及百科发布校验未及时关闭 SQLite 的问题。
