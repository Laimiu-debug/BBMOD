# 0.3.0-rc.27 本地适配版

针对 2026-09-27 提供的狐狸汉化精选合集（50 ZIP、1 RAR），提供可复现的 52 包适配输出。此版本本地构建，尚未发布到官网。

- 修复 MOD 注册常量被其他物品的 ID/Name 覆盖、遗漏多参数依赖、误判 Modern Hooks 旧 API 兼容层和预发布版本依赖。
- 安装、批量启停、方案恢复先检查整个组合，再原子提交；阻止缺前置、两种显星并用、两套完整汉化并用及重复 MOD 注册。
- 安装／启停／卸载／恢复方案自动重建预载并集，保留游戏基础清单；辅助 ZIP 不进入手动方案列表。
- 仓库选择按实际路径安装，防止不同仓库同名文件被一起装入；优先发现 EXE 附近的适配合集。
- 适配输出统一 ASCII 文件名，保留中文展示名；RAR 转为 ZIP；EIMO 内层快速切换道具拆为独立包；铠甲包的 UI 目录旧版本不再作为第二套 MOD 安装。
- 清理军团外套、骨板显示器的重复编译脚本。无限竞技场采用对应汉化源码，仅移除原 MOD 对应的七处冷却刷新，解决源码遮住编译覆盖导致功能失效的问题。

验证：52 个适配包 CRC、Squirrel 源码编译、编译脚本读取、JavaScript 语法检查及管理生命周期验证通过。最终共 2724 个脚本条目。狐狸／BBMOD 独立汉化分别搭配轻度／完整显星，四种组合预检均无阻断错误。完整桌面测试 366 项通过、15 项跳过，后续相关复测 45 项通过（含三项新增）；EXE 在隔离用户配置下自检。

实机边界：首次启动尝试被 Steam 接管，未获得适配组合到达主菜单的证据。原有 MOD 已按 SHA256 恢复。用户随后要求本次只做离线适配；未验证实际战斗、长期存档和所有 MOD 组合，不能视为零运行时错误保证。

复现工具：`tools/prepare_fox_collection.py` 校验 51 个原包哈希后写入独立目录；`tools/audit_fox_collection.py --lifecycle` 在临时游戏目录执行离线校验，不启动游戏。工具的 `--help` 提供必需参数。原始第三方包及其翻译不纳入本项目独立汉化词库。
