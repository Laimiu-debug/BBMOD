# BBMOD 0.3.0-rc.29

本次重新打包修复更新器，版本号仍为 **0.3.0-rc.29**。

- 后续升级时，官方带版本号的 EXE 文件名会同步为新版本；`BBMOD.exe` 和自定义名称保留。
- 旧程序备份改存更新缓存，不再在桌面生成可运行的 `.previous-…exe`；更新失败仍会尝试恢复旧程序。
- 已启用的网页联动会随更新改名同步到新程序路径。

**已安装旧版 rc.29 的用户请重新下载并使用本次 EXE。** 因版本号相同，客户端不会自动提示升级。rc.28 和旧 rc.29 的更新器首次切换仍可能保留旧文件名与桌面备份，直接使用本次下载的 EXE 后，后续升级采用修复后的流程。现有桌面备份请在确认主程序版本和运行正常后退出软件，再手动整理；设置和游戏文件不受影响。

新增整套 MOD 方案分享与一键下载应用。

- 在「MOD 军械库 → 已安装」保存方案后，点击「分享方案」生成官网分享链接。
- 上传前按文件内容核对网站，只补传缺失的 MOD。网站已有的历史版本也可复用，同名不同内容按不同版本处理。
- 文件全部到齐才公开方案；上传中断后再次分享，已成功上传的文件不会重复上传。
- 对方打开方案网页，点击「在 BBMOD 中应用方案」，或在管理器「导入共享方案」粘贴链接，即可预览变更、下载缺失文件并一次应用。
- 优先复用本机已有的相同文件；方案固定分享时的版本，不会自动换成最新版本。已导入方案再次应用时也会核对并补齐文件。
- 下载、校验或兼容检查失败时不改动游戏目录。应用写入失败自动回滚，中断后支持恢复；同名旧文件保留备份。

网站新增「方案广场」及共享方案、补传文件管理。应用方案会禁用方案之外的已启用 MOD，提交前会显示完整变更。

共享范围为直接安装的 MOD ZIP，不包含游戏本体、DLC、存档及 ZIP 外的个人设置。需要的 DLC 和玩法说明可以填写在方案介绍中。单个 MOD 最大 100 MB，每个方案最多 200 个 MOD / 2 GB。

需要从网页打开客户端时，请先在管理器设置中启用网页联动。独立汉化继续使用 rc.9；更新管理器不会替换当前汉化。已完成离线测试与临时目录联调，本次未启动真实游戏。
