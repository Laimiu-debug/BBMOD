# BBMOD 0.3.0-rc.3 · 人物特质筛选测试版

新增开局人物特质筛选，可与能力值组合，也可单独按特质找人。下载附件 **BBMOD.exe** 即可更新，无需 Python；已安装 rc.2 独立汉化的用户无需为本次种子功能重新生成汉化。

## 使用方法

1. 打开「种子远征 → 开局兄弟」，选择「属性与特质」或「仅按特质筛选」。
2. 点击「特质筛选」，搜索并设置「必须具备」「不能拥有」，或保留「不限」。支持原版 58 种随机开局特质。
3. 必选特质选择「全部具备」或「任意一项」，然后设置「至少满足人数」。
4. 例如至少 1 人，近战 ≥90、近防 ≥25，同时具备「高大（巨人）」和「铁肺」，排除「笨拙」。同一个人必须满足所有门槛，不能将不同队员的条件拼在一起。

排除项只约束计入人数的兄弟，其他队员不受限制。起源会影响可出现的特质；互斥特质不能要求同时具备。高级评分和起源预设继续使用各自原规则。

刷种子仍依赖游戏运行：点击「开始远征」，在游戏中选择对应起源并新建战役，随后自动循环筛选。结束时点击「停止并恢复」。特质选择会保存，种子档案和对应 TXT 详情会显示每个人的中文特质。

## 同时修正

- 「只找开局兄弟（快）」此前误用了地图生成分支，会跳过人物筛选；现在使用人物生成与判定分支。
- 特质条件在同一条脚本规则内判断，保证能力值、特质与人数含义一致。
- 界面显示软件版本，便于反馈时确认版本。

## 验证与限制

- **111 项离线回归通过、1 项排除**；排除项会操作真实游戏目录。
- 实际 Squirrel 筛选脚本离线执行 **16 个样例**，覆盖同一人组合、全部／任意、排除、人数、边界值及原有属性筛选。
- 紧凑界面和特质弹窗已离线渲染检查，按钮均在可见范围内；单文件打包后另做资源校验和临时配置自检。
- **本次没有启动游戏。完整刷种子流程仍待游戏内验收。** rc.2 中文启动尝试失败的问题仍未定位，第三方 MOD 组合也未完成实机验收；本版继续标为测试版。
- 独立汉化、地名切换和原生启动组件沿用 rc.2，旧存档的中文地名不会自动还原。

需要自行安装受支持的 Steam 原版 Battle Brothers 1.5.2.3 及相应 DLC。显星和其他第三方 MOD 需另行安装。下载文件的 SHA-256 见附件 `SHA256SUMS.txt`。
