# BBMOD 0.3.0-rc.31

- 修复在线军械库下载汉化包等大文件时，慢速但仍正常传输的连接被固定 3 分钟总时限中断。
- 下载短暂断线、超时或服务器临时出错时，最多自动重试 4 次；服务器支持时从已接收的位置续传，不支持时重新下载。
- 在线下载显示已接收大小、百分比及重试状态；取消后停止重试。
- 共享方案中的缺失 MOD 同样使用下载重试和续传。
- 官网转发线路临时不可用时，自动切换至同一服务器的 HTTPS 备用直连线路；自定义源保持原地址。
- 安装前继续核对文件大小、SHA-256 和压缩包；下载失败不会修改本机 MOD。

官网同时为汉化包、MOD 和共享方案文件启用网关传输、HEAD 和断点续传，减少并发下载占用网站请求线程。原下载链接继续有效，文件每次请求仍检查公开与下架状态。

官网下载按钮使用直连线路，减少大文件经过转发入口时的连接超时。

独立汉化内容继续使用 0.3.0-rc.9；本次修复下载链路。
