# 0.3.0-rc.32

- 健康诊断新增“提交错误报告”入口。预览并编辑报告后，补充复现步骤即可发送到官网，收到回执编号。
- 报告独立保存，最多 60,000 字，不占用详细说明的 5,000 字额度。包含软件与游戏版本、MOD 清单、诊断结果和近期错误日志上下文；隐藏常见个人路径、邮箱与 IP，不上传存档。
- 网络失败保留报告和说明，重试沿用回执凭据以避免重复提交；旧网站未支持报告时明确提示，不会静默丢弃附件。
- 网站管理员可筛选附带报告的反馈、搜索错误关键词或 MOD ID、下载 TXT，并记录处理状态与内部备注。
- 修复独立汉化包被显示成 mod_hooks、误归入框架分类的问题；汉化包身份与内嵌 Hooks 分开显示，共享方案使用正确名称与版本。已有汉化包无需重新生成。
