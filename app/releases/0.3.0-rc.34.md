# 0.3.0-rc.34

- 修复在 MOD 军械库卸载汉化后，汉化管理页仍残留方案名称的问题。卸载最后一份安装副本时同步移除关联汉化方案，自动刷新页面并取消已失效的切换选择。
- 汉化页新增“删除方案”：选中已保存的方案即可清理旧版本留下的记录或尚未应用的方案。保留已安装文件、原包、汉化库副本和恢复备份；需要删除安装文件时在 MOD 军械库卸载。
- 没有已保存方案或已启用 BBMOD 汉化时，不再显示空的 BBMOD 汉化选项。
- 重新启用汉化时移走内容相同的停用副本，避免在军械库重复显示；不同内容的旧包继续保留。
- 卸载文件和关联记录共同支持失败回滚及中断恢复。多文件汉化方案被移除时，其他已安装文件保留。

停用仍会保留汉化，方便重新启用。此次更新只修复管理器，独立汉化包保持 0.3.0-rc.9，无需重新生成汉化。
