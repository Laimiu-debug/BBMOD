# BBMOD 0.3.0-rc.36

官网入口统一为 `https://bbmod.com`。软件更新、在线军械库、MOD 与共享方案下载、种子分享、反馈和错误报告均使用新域名。官网更新不可用时仍可读取 GitHub 发布信息。

已有的官方军械库设置、安装来源和分享链接迁往新官网；用户自定义来源保留。新软件不再回退到 `bbmod.site` 或 `gongpro.cn/bbmod-origin`。旧 EXE 需要手动更换本版。

本版包含阿飞远征起源的固定角色种子生成支持；仅针对软件列出的受支持起源和依赖组合。生成结束恢复原来的 MOD 配置。

新官网：https://bbmod.com/ 。旧版软件请从新官网的下载页手动更换 EXE，之后更新和在线服务均使用新域名。
