# BBMOD 0.3.0-rc.37

MOD 军械库的已安装列表现在显示中文名称、本地版本和官网版本。进入军械库后会在后台检查官网；确认有新版时，MOD 后面显示「更新」按钮。

点击「更新」直接从官网下载、校验并安装，无需再次确认。保留原文件名和启用或禁用状态，旧包自动备份，可在在线军械库恢复上一版。下载进度、取消下载和失败原因直接显示在已安装页面。下载、文件身份或写入校验失败时保留原包；游戏运行和刷种子期间禁止修改 MOD。

手动安装的包通过官网发布文件校验值、可信安装记录或可比较的包版本识别；脚本内部编号与官网版本不同的包不直接比较。没有版本信息的包显示「未识别」，无法确认版本的包不误报更新。已有的 BBMOD 装备读取器也能显示中文名称和版本。

种子远征改为后台读取日志和批量保存，避免大量命中结果堵塞界面。历史列表每页显示 500 条，搜索、分享与导出仍覆盖全部结果；停止生成、更换日志和恢复 MOD 状态保留完整处理流程。

左上角的 BBMOD 图标可点击打开 https://bbmod.com 。本版继续使用新官网，保留阿飞远征起源的固定角色种子生成支持和既有汉化、装备百科、方案管理功能；独立汉化包保持 0.3.0-rc.9。

rc.36 用户可在「设置 → 检查更新」升级。更早的旧官网版本建议从新官网手动下载本版；GitHub 同步提供安装包和更新记录。
