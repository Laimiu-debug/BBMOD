# BBMOD 0.3.0-rc.38

修复已安装 MOD 的测试版更新识别：例如已确认安装的 `0.29.0-preview.12`，现在能识别官网 `0.29.0-preview.13` 为新版并显示「更新」按钮。支持测试版数字序号比较，以及从 preview 升级到 rc 或正式版；不把游戏脚本内部编号当作官网发布版本。

已安装列表的更新列不再留空，直接显示「已是最新」「版本待确认」「未匹配官网」或「本地版本较新」。确认有新版时仍显示行内「更新」按钮，点击后下载、校验并替换原文件，保留启用或禁用状态，自动备份旧包。

无法核实版本时继续等待确认；文件校验、游戏运行和未完成操作检查继续生效。保留已有汉化、方案、种子结果和设置；独立汉化包继续使用 0.3.0-rc.9。

rc.36 及更新版本可在「设置 → 检查更新」升级。更早的旧官网客户端请从 https://bbmod.com/downloads/ 手动下载并更换新版。
