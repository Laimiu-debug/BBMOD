# BBMOD 0.3.0-rc.4 · 版本管理与自动更新测试版

下载附件 **BBMOD.exe** 即可使用，无需 Python。rc.3 及更早版本尚无更新器，需要手动下载本版、关闭旧软件并替换 EXE 一次；之后可直接在软件中检查和更新。

## 新增功能

- 点击右上角「版本与更新」，查看软件版本、内置汉化版本、发布历史与各版本说明；EXE 文件属性也显示版本。
- 默认启动后在后台检查更新；每次成功检查后间隔 6 小时，可关闭自动检查，也可随时手动检查。发现新版会在右上角提示。
- 支持稳定版和测试版通道。本版默认「稳定版 + 测试版」，不会自动降级。
- 软件内下载 EXE，支持取消；下载后核对大小、SHA-256 和程序标识，校验失败不能安装。
- 较新版本下载完成后，可点击「重启并更新」。更新器等待旧软件退出，备份原 EXE、替换并重启；替换或启动进程失败时尝试恢复旧版。备份保存在程序目录，设置保留。
- 正在刷种子或处理文件、MOD 时禁止重启更新。历史版本可以下载留存；源码运行时使用手动替换方式。

## 验证

142 项回归检查通过，另排除 1 项会操作真实游戏目录的检查。覆盖版本排序、通道切换、网络失败与限流、下载取消、异常跳转、损坏文件、并发修改、替换失败恢复、配置保留和界面操作；另核验真实 GitHub 查询与下载、打包资源、打包后联网检查，以及隔离软件副本的替换和重启自检。

## 范围与已知问题

软件更新保留用户配置，不自动重新生成已有汉化 ZIP，不改动游戏或存档。独立汉化和游戏启动组件沿用 rc.2，种子特质筛选沿用 rc.3。

**本次未启动游戏。** 此前隔离副本的中文启动失败仍未定位，完整游戏流程与第三方 MOD 组合尚未验收，本版继续作为测试版发布。软件更新检查需要能够连接 GitHub；断网时可继续使用本地功能。软件替换与重启检查不等于游戏兼容性验收。

需要自行安装受支持的 Steam 原版 Battle Brothers 1.5.2.3 及相应 DLC。其他汉化、显星和第三方 MOD 需另行安装。附件 `SHA256SUMS.txt` 提供下载文件校验值。
