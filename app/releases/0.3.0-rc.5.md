# BBMOD 0.3.0-rc.5 · 在线军械库测试版

## 新增

- 「MOD 军械库 → 在线军械库」：设置自托管网站地址，搜索作品、查看作者说明、版本、前置和冲突信息。
- 下载后核对 SHA-256、大小及 ZIP 结构，再安装到游戏目录。拒绝覆盖未受管理的同名文件。
- 更新备份旧 ZIP，保持 MOD 原有启用或禁用状态，支持恢复上一版；校验失败或记录写入失败时停止/恢复操作。
- 附带可在 Ubuntu 部署的 **BBMOD Hub 0.1.0**：管理员分配作者账号，作者直接公开作品，管理员可下架作品和停用账号；历史版本保留。

## 下载说明

- 玩家只需 `BBMOD.exe`。网站上线后，由站长提供网址，在在线军械库中填写一次。
- 站长下载 `BBMOD-Hub-0.1.0.tar.gz`，按包内 `web/README.md` 部署。没有域名也可以先用服务器 IP；正式分发作者账号前配置 HTTPS。
- 网站的账号、上传文件、数据库与密钥不会随程序分发。本站尚未绑定默认服务器地址。

## 验证与边界

已进行桌面离线回归、独立网站测试、浏览器上传发布和下架流程、手机布局，以及本机 HTTP 网站到隔离游戏目录的实际软件下载/安装。发布检查不启动游戏。

独立汉化和游戏启动组件沿用 rc.2；此前隔离副本的中文启动问题仍未定位，游戏流程与第三方 MOD 组合尚未验收。本版继续作为测试版，不把 ZIP 结构检查当作游戏兼容性验证。

在线安装目前按 MOD ID 检查作者声明的前置和冲突；版本范围、DLC 及存档影响需阅读作者说明。支持可直接放入 data 的单个 ZIP（最大 100 MB），不接收 RAR 或套娃整合包。断网时本地功能仍可使用。
