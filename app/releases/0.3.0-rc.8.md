# BBMOD 0.3.0-rc.8 · 中文地名普通启动修复

本地候选 `dist/BBMOD-0.3.0-rc.8.exe`，内置独立汉化 `0.3.0-rc.3`。尚未上传公共发行列表。

最终文件：桌面 EXE 为 76,947,178 字节；独立汉化 ZIP 为 `dist/mod_bbmod_zhcn-0.3.0-rc.3.zip`，34,474,962 字节。校验值见 [SHA256SUMS](../dist/SHA256SUMS-0.3.0-rc.8.txt)。最终 EXE 的隔离自检及本机 Defender 定向扫描通过；215 项基础回归、追加启动目录保护后的 35 项相关检查均通过。逐项验收与恢复结果见 [本地验收记录](../build/mod-map-candidate/live/acceptance.json)。

- 中文城镇、区域和地点名称经普通 MOD 的 Squirrel/UI 桥接显示；启用汉化包后，BBMOD、Steam 和游戏 EXE 使用相同中文词典。
- 不再分发或调用 `bbmod_launch.exe`、`bbmod_han.dll`，不需要恢复 Defender 隔离文件或更改防护设置。历史检测记录仍保留。
- BBMOD 按当前选定路径使用 Windows 桌面方式启动游戏，不强制添加 Steam 运行环境参数。旧包会提示重新生成并应用。
- 修复游戏 UI 连接时序：在世界地图开始绘制后初始化中文图层；地图不变时复用上一帧，事件遮挡及离开地图时管理显示生命周期。
- 英文实体名、区域名和存档字段保持不变。沿用 2,196 条校对地名展开的 7,723 个名称，正文词库不变。

升级步骤：打开新版 EXE，在「汉化工坊 → 汉化管理与启动」选择「生成 / 更新独立汉化」，查看预览并应用。仅替换 EXE 不会自动升级已经安装的 ZIP。

实机检查在用户授权的正常 Steam 目录进行，先校验备份，再加入禁止保存战役的保护包。检查启动、读取已有存档及中文城镇/区域显示；结束后恢复 MOD 和设置，并逐文件比较游戏数据与存档哈希。日志仍有职业属性范围、Swifter 两个第三方 MOD 的依赖报错，未在本次修改它们。

完整剧情、战斗全流程和任意第三方 MOD 组合尚未完成验收。Defender 的本次结果只代表当前机器和当前签名库，不是跨设备保证。实现与验证证据见 [地图记录](../localization/MOD_MAP_DISPLAY.md)。
