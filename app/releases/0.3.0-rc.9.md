# BBMOD 0.3.0-rc.9 · 指定红武器筛选

此前「营地红装」只能筛全地图红装总数。本版可选择 50 种具体红武器，设置最低数量及可选的伤害、穿甲品质门槛。例如「红标枪至少 2 件，伤害和穿甲品质均 ≥75%」要求两件武器分别同时达标。

使用方式：打开 `dist/BBMOD-0.3.0-rc.9.exe`，进入「种子远征」，选择「只找红装 → 营地红装 → 指定红武器」，设置条件后开始远征。也支持「人物 + 红装」「人物 + 地图 + 红装」。无需重新生成汉化包，独立汉化仍为 `0.3.0-rc.3`。

- 类型包含红标枪、红投斧、红大剑、红刺剑、红双手锤等，也可选择任意红武器或单手近战、双手近战、远程／投掷大类。
- 品质为加成在可随机范围内的位置，100% 为满值。0% 仍要求存在该加成，「不限」则不要求。当前一次筛选一种具体类型或大类。
- 保留原总数筛选。指定武器与总数独立切换，不把总数条件作为放行指定武器的备选条件；设置会保存。
- 结果详情展示具体红武器名称、随机品质及最终伤害、穿甲等属性。
- 刷种子与普通启动复用已验证的 Windows 桌面启动方式，以及 Steam 注册目录校验，避免复制的游戏启动到未受本次文件保护的目录。

验证：232 项回归检查通过；离线原生 Squirrel 解释器执行实际营地判定器的 20 个条件用例，以及「只找红装」主循环的命中／未命中分流。核对全部 50 种武器 ID 与本地官方脚本一致。真实 Qt 页面在 1360×880 和 1080×720 下检查了字段可见范围及键盘操作；界面截图使用明确标记的测试记录，不代表找到真实种子。相关报告位于 `build/review/rc9-tests.xml` 和 `build/review/seed-weapons/`。

筛选范围为地图生成时的营地红装，可用类型取决于已安装的 DLC。没有在本次测试中启动游戏、改动实际游戏目录或进行实机长时间搜索。沿用上一版普通 MOD 中文地名修复，不包含旧注入组件。本版仅生成本地文件，尚未发布到公共发行列表。
