# BBMOD 0.4.0

闪退和报错排查：

- 错误报告自动推断可疑 MOD。根据报错和调用栈中的脚本路径，找出实际生效的那份文件属于哪个 MOD；同一文件被多个 MOD 覆盖时一并提示。框架 MOD（Hooks、MSU）的包装调用权重较低，只涉及原版脚本时如实说明无法定位。营地诊断的运行时报错也使用同一归因。
- 自动记住「上次正常退出（自动）」：从 BBMOD 启动的游戏正常退出后，记录当时启用的 MOD 组合。出问题时可在错误报告窗口或「应用方案」一键恢复。该名称由软件维护，用户方案不能占用；重命名后成为普通方案。
- 新增「排查问题 MOD」：每轮只启用一部分 MOD 及其前置，按「问题仍然出现 / 没有出现问题」逐步缩小范围，十几个 MOD 通常四五轮即可定位；两个 MOD 只在同时启用时冲突也能找出。进度保存在本机，关闭软件后可继续；结束时可完全恢复原组合，或恢复后禁用问题 MOD。排查期间不更新「上次正常退出」记录。

修复：

- 后台任务结束时，同一线程的其它收尾步骤可能被跳过，偶发导致 MOD 管理一直处于“忙碌”状态。

独立汉化包继续使用 0.3.0-rc.9，无需重新生成或更换。
