# BBMOD 0.5.0

新增「存档分享」：选择本机战役，核对当前启用的整套 MOD 后一起分享。记录游戏版本、DLC 和每个文件的固定版本；网站已有相同文件会复用，只补传缺失文件。存档与所有 MOD 齐备后才公开。

「存档广场」支持搜索、分页、网页详情及链接导入。接收方先核对游戏版本、DLC 和 MOD 变更，再下载并恢复整套环境。存档另存为新文件，原存档保留；其他 MOD 停用并备份。写入失败一起回滚，中断后可在原存档目录恢复上次导入。网页提供存档与 MOD 的完整 ZIP 包。

修正汉化识别：MSU 中文版、营地红装信息和显星等辅助 MOD 不再仅因文件名含中文而计入多套游戏本体汉化。实际文件覆盖冲突检查保留。

分享前需退出游戏，并确认当前 MOD 仍是所选战役使用的组合。记录的是分享时的游戏环境，无法从存档可靠反推后来更换过的 MOD。分享不包含游戏本体、DLC 和 ZIP 外的个人设置；接收方需自行安装相同游戏版本及 DLC。
