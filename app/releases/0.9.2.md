# BBMOD 0.9.2

- 修正旧 Hooks 的包名识别：多个包共用 `mod_hooks` 注册 ID 时，不再把纯旧 Hooks 显示为狐狸汉化，也不再仅凭该 ID 为重命名的汉化包关联框架下载。已验证的安装记录、包身份和明确文件名继续用于识别。
- 修正疑似闪退报告的错误摘要：跳过 `Script Stacktrace` 等堆栈标题和通用异常结尾，显示日志中更具体的错误；原始日志继续保留。
- 内置汉化构建资源同步已发布的独立汉化 0.3.3 军队、佣兵团名称修订。更新管理器不会自动替换游戏中已安装的汉化包。

以上修复改善包名识别与诊断信息。缺少原始 MOD 包或存档的第三方兼容问题仍需按反馈中的排查步骤确认，不能据此认定读档崩溃已修复。
