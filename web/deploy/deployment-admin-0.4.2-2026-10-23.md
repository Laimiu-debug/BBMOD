# 官网 0.4.2：后台管理页面优化

2026-10-23 已部署至 [BBMOD 官网后台](https://bbmod.com/manage/)。桌面推荐版本保持 **0.8.2**；本次没有接入广告。

## 页面与操作

- 统一工作台、反馈、种子、共享方案、存档、百科报告、管理器版本、作者账号及密码重置页面的管理导航。
- 工作台集中展示待查看和处理中的反馈、作品概况、访客统计及常用入口；诊断报告和未回复反馈可直接进入。
- MOD 列表支持按标题、安装文件名和作者搜索，按下架状态筛选；下架和恢复后保留搜索、状态及页码。下架原因和原有确认、CSRF、审计记录继续保留。
- 作者账号按 50 条分页；共享方案和补传文件翻页时保留另一列表的页码。
- 管理器历史版本的更新说明、流量统计说明和操作记录按需展开。后台样式仅在管理页面加载，窄屏导航和列表可正常使用。
