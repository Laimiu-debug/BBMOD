# 官网反馈处理与桌面 0.9.2

2026-10-31（Asia/Hong_Kong）已发布 [BBMOD 0.9.2](https://bbmod.com/downloads/)。网站继续运行 0.4.2，独立汉化保持已发布的 0.3.3。

## 已发布修复

- 已装 MOD 的离线名称和官网作品匹配不再仅凭 `mod_hooks` 这一共用注册 ID，把纯旧 Hooks 与狐狸汉化互相误认。独立包身份、明确文件名和经哈希验证的安装回执仍有效。
- 疑似闪退摘要跳过堆栈标题；具体 critical 错误优先，通用 fatal 与更早普通错误同时存在时明确区分“此前日志”，不把它直接当作崩溃原因。完整日志仍保留。
- 桌面内置汉化资源同步已经发布的 0.3.3 军队与佣兵团名称修订；六个源文件 SHA 与该次发布 gate 一致。本次不会自动替换用户游戏内汉化，也未新增游戏内视觉验收。

服务器正式 Hooks ZIP 为 10,782 字节、7 个条目；5 个原始游戏文件逐项 SHA 与来源一致，另外两个文件为署名和许可说明，实际注册版本为 21.1。未发现混入狐狸汉化。公开小包下载曾在本机代理链路超时，因此原件结论来自严格核验 SSH 身份后的服务器文件检查，不冒充公开下载验收。

## 验证

- 12 个相关测试模块共 **279 项通过，0 跳过**，覆盖安装包识别、在线目录、崩溃报告、汉化和更新器。不是本次完整桌面全量回归。
- 成品隔离自检通过；117 个 Python 模块及入口字节码匹配源码，3,964 项资源匹配构建清单。新增军队名称表同时纳入显式资源检查。
- 使用 0.9.1 EXE 内置更新器完成隔离升级、重启及新版本自检，原测试设置保留。未启动真实游戏或加载用户存档。

## 反馈处理边界

本次核对 9 条新记录：6 条无关营销关闭，3 条真实问题记录排查结果并保持处理中；原文及原有回复完整保留，其他反馈未改。处理前另作 3,993,600 字节 SQLite 在线快照，位于 `/srv/data/deployments/feedback-20261031/before.sqlite3`。

- Hooks 名称误认已修复，但用户尚未提供具体失效旧 MOD 的名称、版本与日志，不能声称全部兼容问题解决。
- MSU 已加载，Legends 注册对象查询失败。Clearer Combat Log 的作者将 Legends 列为可选项；需先禁用该 MOD 进行对照并取得原包，不能凭相邻日志认定唯一原因或要求安装 Legends。
- 读旧存档时的 `getID`、类未注册和异常退出仍需原存档、原 MOD 组合及复测日志；摘要修复不等同于存档修复。既有四条处理中记录缺少新资料，未重复结案。

三条站内回复草稿保存在本地忽略目录，发送需另有明确授权；本次处理操作只更新状态和内部备注，没有新增回复。私有反馈、回执、联系信息和完整诊断不进入本发布记录。
