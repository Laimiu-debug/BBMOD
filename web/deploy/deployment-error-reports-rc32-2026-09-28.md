# 错误报告收集 rc.32 · 2026-09-28

桌面 **0.3.0-rc.32** 与网站报告收集功能已发布。独立汉化仍为 rc.9，无需重做汉化包。

## 使用

- 健康诊断 → 提交错误报告 → 预览修改 → 补充复现步骤 → 提交，成功获得回执编号。
- 诊断报告作为独立文本附件，最多 60,000 字；详细说明仍最多 5,000 字。包含软件、系统和游戏版本、MOD 文件与注册版本、诊断结果、近期游戏日志及错误上下文。仅发送用户确认的内容，不上传存档；常见个人路径、邮箱与 IP 先脱敏。
- 网络失败保留当前草稿，重试复用提交凭据。网站若不支持附件，客户端明确提示而不静默丢弃报告。
- 管理员入口：`/manage/suggestions/?reports=1`。可按错误关键词、MOD ID、版本搜索，查看报告、下载 TXT，记录处理状态和内部备注；匿名用户及普通作者无权读取报告。
- 同时修复 BBMOD 独立汉化被显示为 `mod_hooks` / 框架的问题，以及旧报告预览弹窗读取 Qt 返回值导致无法进入草稿的问题。
