# 存档分享发布：桌面 0.5.0 / 网站 0.3.8

2026-10-11 发布至 https://bbmod.com。桌面推荐稳定版为 0.5.0，独立汉化仍为 0.3.2。未修改或公开上传本机真实游戏存档。

## 功能

- 桌面「存档分享」读取本机战役，分享时附带当前启用的全部 MOD ZIP，记录游戏版本、DLC、大小和 SHA-256。相同内容复用；存档和所有 MOD 就绪后才公开。
- 网站 `/saves/` 提供搜索、分页、战役详情、`bbmod://saves/` 联动与包含存档、MOD 和清单的完整 ZIP 下载。
- 接收者先预览固定版本的 MOD、下载和停用变更，核对游戏版本与 DLC；另存新战役文件，保留已有存档。存档、MOD 和方案元数据通过同一事务写入，失败回滚，中断后在原目录恢复。
- 管理后台支持下架分享与存档文件；必需 MOD 或存档下架后，整套下载及恢复关闭。
- 修正 MSU 中文版、营地红装信息、显星等辅助 MOD 仅因文件名被误认为另一套游戏本体汉化的问题。实际覆盖冲突检查保留。

分享者仍需确认当前 MOD 确实对应所选战役。存档无法可靠反推后来更换过的 MOD；游戏本体、DLC 和 ZIP 外设置未包含。
