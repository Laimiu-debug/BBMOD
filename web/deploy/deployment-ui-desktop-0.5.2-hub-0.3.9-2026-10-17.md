# 桌面 0.5.2 与官网 UI 0.3.9 发布

2026-10-17（UTC+8）已发布桌面 **0.5.2** 为推荐稳定版，并上线网站 **0.3.9**。

发布前发现本地基线落后于线上，已保全 UI 改动并快进到 `5f48d0a` 后移植，保留 0.5.1 的存档分享、种子异常处理和 Steam／GOG 识别等功能。独立汉化维持 **0.3.2**。

## 内容

- 桌面页面切换使用可中断的轻量过渡；设置提供「减少动态效果」。改善营地引导、诊断空状态、按钮与表格对比度。详见 [0.5.2 说明](../../app/releases/0.5.2.md)。
- 官网加入卡片进场与悬停反馈，优化首页下载入口、搜索区和手机布局；减少动态效果支持本机偏好与系统设置。
- 网站只在当前已验证镜像上覆盖六个相关文件，重新生成静态文件；保留线上其余代码、存档广场和百科。静态资源使用 `?v=0.3.9` 防止旧脚本缓存漏掉初始化。
