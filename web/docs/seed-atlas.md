# 种子地图与跑商

[种子广场](https://bbmod.com/seeds/)的总入口、每张种子卡和种子详情均可打开「地图与跑商」。
地图页地址为 `/seeds/map/?seed=46U2HMOORH`，种子码为区分大小写的十位 ASCII 字母或数字。

地图显示中文城镇、地形和道路，支持拖动、缩放、全图、14–30 像素字号、地区名称及全部营地图层。
右侧三个页签提供城镇特性与设施、特产市场及买卖建议、多站跑商路线和营地红装列表。
红装选择会居中对应营地，显示坐标、最近城镇的方向与距离、营地强度和实际属性；武器包含实用词条评分和 roll 品质。

解算基准为原版 1.5.2.3、全部官方 DLC。营地和红装基准固定为农民民兵、战斗／经济／资金专家的开局，
不承诺其他起源、难度或 MOD 得到相同营地。行情以中立关系、没有临时事件为基准，件数不是库存保证；
行程不模拟停留、战斗、夜间及海运。所有名称复用 BBMOD 已审核的汉化映射。

## 运行与缓存

- `GET /api/v1/worldmaps/<seed>/` 读取完整地图。未缓存时立即返回 202，并给出 `Retry-After: 3`；后台完成后返回 200。
- `POST /api/v1/worldmaps/<seed>/route/` 接收 `stops` 城镇索引数组和可选的布尔 `road_only`，需要正常 CSRF Cookie 和请求头。最多十二站。
- 一个操作系统文件锁限制服务器同时只有一个解算任务；重复轮询不重复扣额度或启动解算器。
- 新地图额度为每 IP 每小时 20 次、全局 100 次；新路线为每 IP 每小时 180 次、全局 1200 次。缓存命中不扣额度。
- 来源使用站点密钥的 HMAC 摘要，沿用网关覆盖的真实地址，不保存原始 IP。
- 缓存位于数据目录的 `worldmap-cache`，按网站版本、组件指纹、区分大小写的种子以及路线参数区分。
- 一次计算最多 150 秒，失败保留 60 秒冷却；页面自动等待最多三分钟。缓存限制为 512 个结果文件、128 MiB。

## 构建

先按桌面离线地图文档准备并验证原版规则、补丁后的 Squirrel 3.1 源码及独立组件，再运行：

```powershell
python -B web/tools/package_atlas.py
python -B web/tools/package_hub.py
```

`package_atlas.py` 从现有汉化词库生成精简网页映射，校验原版对照指纹，生成带清单的 Linux 构建上下文。
`web/Dockerfile` 支持完整构建；`web/deploy/atlas.Dockerfile` 用于针对已核实的线上基础镜像制作指定文件覆盖层。
不要把尚未发布的本地中间件、私有数据、凭据或玩家文件混入覆盖层。Squirrel 的版权与许可随组件保留。

服务器原版对照可运行 `python tools/validate_atlas_runtime.py`，比较五张完整地图、十组营地和红装夹具。
新接口专项为 `python manage.py test catalog.test_worldmaps`。极简服务器镜像不带桌面 MOD 管理模块；
完整存档桌面联动测试应在完整本地项目中运行。
