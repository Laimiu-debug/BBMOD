第一次使用？按这三步来

从零安装汉化与阿飞起源：图文教程和 PDF →

  1. 确认游戏目录

    运行 BBMOD，确认自动找到的《战场兄弟》目录；也可手动选择。当前针对 Windows 游戏版本 1.5.2.3。

  2. 检查当前汉化

    进入「汉化管理」查看当前启用的包。已有可用汉化可直接使用，需要更换时导入新版 ZIP 并预览切换。

  3. 安装你的第一个 MOD

    在「在线军械库」连接官网，查看前置、冲突与存档影响后安装；本地 ZIP 可在已安装页直接导入。

禁用会保留文件，可再次启用；卸载会移除安装文件。仓库中的原始压缩包仍可用于重新安装。

从网页打开 BBMOD

使用 rc.26 或更新版，在软件「设置 → 官网联动」点击「启用『用 BBMOD 打开』」。之后，网页 MOD 会打开对应作品，网页种子会显示收藏预览。

浏览器询问是否打开 BBMOD 时，选择打开即可。没有弹出软件时，先启动新版并启用联动；移动 EXE 后需要重新启用。旧版仍可下载 ZIP 或复制种子码。

常见问题：前置、旧存档与安装失败

缺少前置时，先启用已安装的框架，或在营地诊断里点击「查找前置」。版本范围需满足作者要求，未支持的比较格式会提示人工确认。

安装失败后先阅读具体原因：压缩包损坏需重新下载，同名文件需先处理；意外中断时可在已安装页点击「恢复上次操作」。更换影响存档的 MOD 前请自行备份游戏存档。
